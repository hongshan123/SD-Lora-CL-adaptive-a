# Live-A / Frozen-A implementation family

This directory preserves the separate Live-A/Frozen-A branch's source,
configurations and tests. Run its entrypoints from this directory after
providing local datasets and pretrained weights. Its backbone and consolidation
variants are isolated from the current HOEP implementation at the repository
root to preserve their experimental semantics.

Logs, checkpoints, snapshots, metrics and completed-run reports are excluded.
Update server-specific paths in configuration templates before use. The
upstream license and requirements are retained.
